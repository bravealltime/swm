# 🛡️ AegisLink v2 — ปลั๊กอิน SWEX สำหรับเว็บ SWM (เรียลไทม์)

ติดตั้งครั้งเดียวใน **Summoners War Exporter (SWEX)** แล้วเว็บ SWM จะเห็นกล่องมอนสเตอร์ รูน
อาร์ติแฟกต์ และข้อมูลกิลด์/Siege ของคุณแบบเรียลไทม์ — เปลี่ยนรูนในเกม หน้าเว็บขยับตามทันที
ไม่ต้อง export ไฟล์ JSON อีก

## ทำงานอย่างไร

1. ตอนล็อกอินเกม (`HubUserLogin`) ปลั๊กอินเก็บกล่องทั้งหมดไว้ในหน่วยความจำ
2. ทุกแพ็กเก็ตหลังจากนั้นที่มี `unit_info` / `rune` / `artifact` (อัปเกรด ใส่ ถอด ขาย ตื่นตัว ฯลฯ)
   ถูกนำมาปรับสถานะให้ตรงกับเกมเสมอ
3. ปลั๊กอินเปิดเซิร์ฟเวอร์เล็ก ๆ ที่ `http://127.0.0.1:7391` (เปลี่ยนได้ที่ `livePort`)
   - `GET /status` — สถานะ
   - `GET /snapshot` — กล่องทั้งหมดล่าสุด
   - `GET /guild` — แพ็กเก็ตกิลด์/Siege ล่าสุด
   - `GET /events` — สตรีม Server-Sent Events: `snapshot`, `delta`, `guild`
4. เว็บ SWM (หน้า *กล่องของฉัน* และ *ห้องบัญชาการกิลด์*) เชื่อมต่อสตรีมนี้จากเบราว์เซอร์ของคุณเอง

ข้อมูลไม่ออกจากเครื่องคุณ: เซิร์ฟเวอร์ผูกกับ 127.0.0.1 เท่านั้น และตอบเฉพาะคำขอจาก
`https://swm-blue.vercel.app` / `localhost` (ตรวจ `Origin`) เว็บอื่นที่เปิดอยู่จะอ่านไม่ได้

## ติดตั้ง

1. คัดลอกโฟลเดอร์ `aegislink` (มี `index.js` + `package.json`) ไปไว้ที่โฟลเดอร์ปลั๊กอินของ SWEX
   (Windows: `%USERPROFILE%\Documents\Summoners War Exporter Files\plugins\` หรือกด
   *Open plugins folder* ในแท็บ Plugins ของ SWEX)
2. ปิด-เปิด SWEX → แท็บ **Plugins** → เปิด **AegisLink** — log ต้องขึ้น `live server ready`
3. ที่เว็บ SWM กด **เชื่อมต่อ SWEX** (หน้า *กล่องของฉัน*) — ถ้า Chrome/Edge ถามสิทธิ์
   "เข้าถึงอุปกรณ์ในเครือข่ายในเครื่อง" ให้กดอนุญาต
4. เข้าเกมผ่าน SWEX 1 ครั้ง ปลั๊กอินจะส่งกล่องทั้งหมดมา จากนั้นทุกอย่างอัปเดตเอง

## ตัวเลือก

| ค่า | ความหมาย |
| --- | --- |
| `livePort` | พอร์ตเซิร์ฟเวอร์ในเครื่อง (ค่าเริ่มต้น 7391) |
| `syncAccount` | ส่งกล่องมอนสเตอร์/รูน/อาร์ติแฟกต์แบบเรียลไทม์ |
| `syncGuild` | ส่งแพ็กเก็ตกิลด์ / Siege / World Guild Battle |
| `allowedOrigins` | เว็บอื่นที่อนุญาตให้อ่าน (คั่นด้วยจุลภาค) ปกติเว้นว่าง |
| `endpointUrl`, `apiKey` | (ไม่บังคับ) ส่งสรุปผลการรบไปเซิร์ฟเวอร์ของคุณเองแบบ POST |
| `log3MDC`, `logSiege`, `logGuildWar`, `logDungeonDrops` | เลือกสรุปที่จะส่งไป `endpointUrl` |

## แก้ปัญหา

- **ไม่พบปลั๊กอิน** — ตรวจว่าไฟล์อยู่ที่ `plugins/aegislink/index.js` แล้วรีสตาร์ต SWEX
- **EADDRINUSE** — พอร์ตชน เปลี่ยน `livePort` แล้วตั้งพอร์ตเดียวกันที่หน้า AegisLink บนเว็บ
- **เชื่อมต่อได้แต่กล่องว่าง** — ต้องเข้าเกม (หน้า Login) หลังเปิดปลั๊กอิน 1 ครั้ง
- **ข้อมูลกิลด์ไม่มา** — เกมส่งแพ็กเก็ตเหล่านี้เมื่อคุณเปิดหน้ากิลด์ / แผนที่ Siege / บันทึกการรบ
